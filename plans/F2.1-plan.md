## Patterns Applying

- Linked versus copied files: Yes — update source files directly; do not edit generated symlinks. Skeleton files are copied into projects, so the phase-1 documentation changes must be represented in the project-owned template and root dogfood files.
- Single source of truth for the skill set: No — phase 1 does not add, remove, or rename a command or modify `claude-stubs/`.
- Scripts run from a project root: No — phase 1 does not modify scripts or link-management behavior.
- Test through behavior and temporary paths: Yes — the new pytest module should inspect repository content without writing to the real working tree, following `tests/test_template.py` conventions.
- Generated files: Yes — do not edit generated symlinks or `codex-skills/*` by hand; neither is in the phase-1 file list.
- Releases: No — `CHANGELOG.md` and `VERSION` are explicitly phase-3-only and must not be changed in F2.1.
